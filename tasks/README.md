## Roadmap inicial

### 001 — Estrutura e identidade visual

Criar a estrutura de pastas, arquivos-base, variáveis CSS, tipografia, cores, layout global e componentes compartilhados.

### 002 — Login demonstrativo

Criar a tela de login e a navegação demonstrativa para o dashboard, sem autenticação real.

### 003 — Dashboard

Criar o resumo visual do condomínio com indicadores e atalhos para os módulos.

### 004 — Moradores

Criar listagem, cadastro demonstrativo e detalhes de morador.

### 005 — Unidades

Criar a listagem de unidades e a relação demonstrativa entre unidade e morador.

### 006 — Ocorrências

Criar listagem, status e formulário demonstrativo de ocorrência.

### 007 — Reservas

Criar listagem e formulário demonstrativo de reserva de área comum.

### 008 — Revisão e acabamento

Validar navegação, responsividade, acessibilidade básica, console, consistência visual e escopo.

## Regra de avanço

Uma tarefa só é encerrada depois de explicar o resultado, testar o fluxo e registrar eventuais decisões. A próxima tarefa começa somente após uma nova solicitação.
